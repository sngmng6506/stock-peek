FAQ

Windows shows a warning when I install.
It’s an independent project without code signing, so SmartScreen warns about it. Click “More info” → “Run anyway”. You can also read the source on GitHub and build it yourself.
Where do the quotes come from?
Naver Finance for Korean stocks and Yahoo Finance for US, Japanese, Indian and Saudi stocks (Japanese quotes are delayed 20 minutes, Saudi quotes 15 minutes). Prices refresh every 3 seconds during market hours and every 60 seconds after close, and may lag the market depending on the provider.
Does it work on a work PC?
It uses your Windows proxy and certificate settings, so it’s built to work on corporate networks. If your company blocks installs, you won’t be able to use it.
How do I install it on a Mac?
It runs on macOS 12 or later. Open the downloaded file and move the app to Applications. As an independent app it isn’t notarized by Apple, so macOS blocks the first launch. Go to System Settings → Privacy & Security and click “Open Anyway”. There’s no automatic install on Mac; when a new version is out, click the notification and download it again.
