FAQ

Windows shows a warning when I install.
It’s an independent project without code signing, so SmartScreen warns about it. Click “More info” → “Run anyway”. You can also read the source on GitHub and build it yourself.
Where do the quotes come from?
Naver Finance for Korean stocks and Yahoo Finance for US stocks. Quotes may lag the market depending on the provider.
Does it work on a work PC?
It uses your Windows proxy and certificate settings, so it’s built to work on corporate networks. If your company blocks installs, you won’t be able to use it.
Is there a Mac version?
Windows 10 and 11 only for now.
