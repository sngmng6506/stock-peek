アップデートの仕組み

アプリは起動時、1時間ごと、パネルを開いたとき（15分に1回まで）に GitHub Releases の新しいバージョンを確認します。Windows ではバックグラウンドでダウンロードしたあと通知が表示され、クリックするとすぐに更新して再起動します。Mac はコード署名がないため自動インストールができず、通知をクリックするとダウンロードページが開きます。

動作環境と注意事項

  • 対応 OS: Windows 10・11、macOS 12 以降
  • インターネット接続が必要です。会社のセキュリティポリシーやインストール権限によっては使えない場合があります。
  • 個人開発のアプリでコード署名がないため、Windows では SmartScreen の警告が表示されることがあり、Mac では初回起動時にシステム設定での許可が必要です。
  • 表示される株価は公式の約定データや投資助言ではありません。日本株の株価は20分、サウジ株は15分遅れです。
  • ファイル確認用の SHA-256 チェックサムは GitHub のリリースに添付しています。
