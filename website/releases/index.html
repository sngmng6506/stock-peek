최신 버전과 업데이트 내역

현재 배포 중인 Windows·Mac 설치 버전과 변경 사항을 확인할 수 있습니다. 몰래주식은 GitHub Releases를 통해 배포되며 앱 안에서도 새 버전을 자동으로 확인합니다.

최신 버전 v1.6.27

GitHub Releases에서 배포 중

한국·미국·일본·인도·사우디 관심 종목 시세, 최근 3개월 차트, 평가손익, 멀티모니터 배치와 업데이트 알림을 지원하는 Windows 10·11과 macOS 12 이상용 버전입니다.

자동 업데이트 방식

설치된 앱은 시작할 때, 이후 1시간마다, 그리고 패널을 열 때(15분에 한 번까지) GitHub Releases의 새 버전을 확인합니다. Windows는 새 버전을 백그라운드에서 내려받은 뒤 알림을 띄우고, 알림을 누르면 바로 설치하고 다시 실행합니다. Mac은 서명 문제로 자동 설치가 안 되므로 알림을 누르면 다운로드 페이지가 열립니다.

지원 환경과 주의사항

  • 지원 운영체제: Windows 10·11, macOS 12 이상
  • 인터넷 연결이 필요하며 회사 PC에서는 보안 정책이나 설치 권한에 따라 제한될 수 있습니다.
  • 개인 개발 앱이라 코드 서명 인증서가 없어 Windows SmartScreen 안내가 표시될 수 있고, Mac은 처음 실행할 때 시스템 설정에서 허용해야 합니다.
  • 표시되는 시세는 공식 주문 체결 데이터나 투자 조언이 아닙니다.
  • 파일 확인용 SHA-256 체크섬은 GitHub 릴리스에 함께 있습니다.

최근 릴리스
