3개월 일봉 차트

종목마다 최근 3개월 흐름을 작은 차트로 보여줍니다. 장이 끝나거나 주말이어도 마지막 가격과 차트는 그대로 남습니다.

트레이에 두고 잊어도 됩니다

Windows 시작 시 자동 실행을 켜두면 따로 신경 쓸 일이 없습니다. 시세는 장중 3초, 장 마감 후 60초마다 갱신합니다.

관심 종목, 보유 수량, 평균 매입가, 설정은 PC에만 저장되고 따로 수집하지 않습니다.

자주 묻는 질문

설치할 때 Windows 경고가 떠요.
개인이 만든 앱이라 코드 서명이 없어서 SmartScreen 경고가 뜹니다. “추가 정보” → “실행”을 누르면 설치됩니다. GitHub에서 소스를 보고 직접 빌드해도 됩니다.
시세는 어디서 가져오나요?
한국 종목은 네이버 금융, 미국 종목은 Yahoo Finance의 공개 데이터입니다. 제공처 사정에 따라 실제 시세보다 늦을 수 있습니다.
회사 PC에서도 되나요?
Windows의 프록시·인증서 설정을 그대로 쓰기 때문에 사내망에서도 동작하도록 만들었습니다. 회사 정책으로 설치가 막혀 있다면 쓸 수 없습니다.
Mac은 지원하나요?
아직 Windows 10·11만 지원합니다.
