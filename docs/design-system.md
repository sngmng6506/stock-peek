# 디자인 시스템

패널 UI의 실제 값. 코드: `src/renderer/src/assets/main.css` (CSS 변수 없이 값 직접 사용). 값을 바꾸면 이 문서도 같이 고친다.

## 색상

어두운 반투명 패널 하나만 지원한다 (라이트 테마 없음).

| 이름             | 값                                                | 사용처                             |
| ---------------- | ------------------------------------------------- | ---------------------------------- |
| 패널 배경        | `rgba(23, 25, 29, 0.96)` + `blur(18px)`           | `.panel`                           |
| 모달 배경        | `rgba(28, 30, 38, 0.98)`                          | `.modal`                           |
| 본문 글자        | `rgba(235, 235, 245, 0.92)`                       | 패널 기본                          |
| 보조 글자        | `rgba(235, 235, 245, 0.5–0.6)`                    | 종목 코드, 안내, 라벨              |
| 선·면            | `rgba(255, 255, 255, 0.04 / 0.06 / 0.08 / 0.12)`  | hover 배경, 테두리 (밝을수록 강조) |
| 주요             | `#2d6cdf` (hover `#3a7be8`)                       | 주요 버튼, 선택된 시장             |
| 상승             | `#2eb872`                                         | 등락률, 평가손익                   |
| 하락·오류        | `#e0584a`                                         | 등락률, 평가손익, 오류 문구        |
| 차트 상승 / 하락 | `#0F6E56` / `#A32D2D`                             | `Sparkline.jsx` 선                 |
| 지연             | `rgba(235, 180, 80, 0.8)`                         | 갱신 실패 점 (`.stale-dot`)        |
| 포커스           | `rgba(235, 235, 245, 0.75)` 1px outline, 2px 간격 | 키보드 포커스                      |

상승·하락은 색과 함께 `+`·`-` 부호로도 구분한다 (`formatRatio`, `formatMoney signed`). 상승=초록, 하락=빨강은 모든 시장·언어 공통.

## 글꼴

| 이름 | 값                                   | 사용처                      |
| ---- | ------------------------------------ | --------------------------- |
| 글꼴 | 시스템 sans-serif (`base.css`)       | 전체                        |
| 숫자 | `font-variant-numeric: tabular-nums` | 가격·등락률 (자릿수 정렬)   |
| 본문 | `13px`                               | 패널 기본, 종목명, 입력칸   |
| 보조 | `11–12px`                            | 종목 코드, 버튼, 안내, 오류 |
| 제목 | `14px` (모달), `16–18px` (환영 화면) |                             |

패널은 기준 폭(`shared/panelSize.js`)에서 설계하고 사용자가 크기를 바꾸면 `zoom`으로 전체를 비례 확대한다. 글자 크기를 따로 바꾸지 않는다.

## 간격과 형태

| 이름      | 값                                                                       | 사용처   |
| --------- | ------------------------------------------------------------------------ | -------- |
| 카드 안쪽 | `10px 12px`, 줄 간격 `4px`                                               | `.card`  |
| 모달 안쪽 | `16px`, 요소 간격 `12px`                                                 | `.modal` |
| 모서리    | 패널 `12px`, 모달 `10px`, 카드 `8px`, 버튼·입력 `6px`, 아이콘 버튼 `4px` |          |

## 컴포넌트

- **카드**: 이름·등락률 / 가격·지연·차트 / 보유 시 수량·평가손익. 편집·삭제 버튼은 hover·포커스 때만 표시
- **오류 카드**: 종목 코드 + 번역된 오류 문구, 반투명
- **모달**: 패널 안에 열림. 열린 동안 패널 자동 숨김 중지 (`panel:lock`). 버튼은 오른쪽 정렬, 주요 버튼이 맨 오른쪽. 진행 중에는 버튼을 비활성화해 중복 실행을 막는다
- **아이콘 버튼**: `title`·`aria-label` 필수 (번역 문구)
