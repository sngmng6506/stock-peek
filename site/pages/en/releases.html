Automatic updates

The installed app checks GitHub Releases at launch, every hour, and when you open the panel (at most every 15 minutes). On Windows the update downloads in the background and a notification appears; clicking it installs the update and restarts the app. On Mac automatic install isn’t possible without code signing, so the notification opens the download page instead.

Requirements and notes

  • Supported operating systems: Windows 10 and 11, macOS 12 or later
  • An internet connection is required. Corporate security policy or install permissions may restrict use.
  • Because the independent app is not code-signed, Windows SmartScreen may display a notice, and on Mac the first launch must be allowed in System Settings.
  • Displayed quotes are not official execution data or investment advice.
  • SHA-256 checksums for verifying downloads are attached to each GitHub release.
