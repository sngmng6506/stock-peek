# 몰래주식 (Stock Peek)

[![Download](https://img.shields.io/github/v/release/sngmng6506/stock-peek?label=download&style=flat-square)](https://github.com/sngmng6506/stock-peek/releases/latest)
[![License](https://img.shields.io/badge/license-MIT-blue?style=flat-square)](LICENSE)

화면 가장자리에 마우스를 대면 관심 종목 시세가 슬라이드로 나타나는 Windows 위젯. 한국·미국 주식 지원.

**[stock-peek.com](https://stock-peek.com/)** · [English](https://stock-peek.com/en)

## 다운로드

[Releases](https://github.com/sngmng6506/stock-peek/releases/latest)에서 `stock-peek-setup.exe`. 이후 업데이트는 앱 안에서 자동.

## 기능

- 가장자리 hover로 패널 표시/자동 숨김, 좌·우 배치, 멀티모니터
- 한국(네이버 금융)·미국(Yahoo Finance) 종목 검색
- 보유 수량·평균 매입가 입력, 평가손익, 3개월 일봉 미니 차트
- 드래그 순서 변경, 한국어/English, 트레이 상주, 시작 시 자동 실행
- 적응형 갱신(장중 3초 / 장외 60초), 네트워크 오류 시 마지막 가격 유지

## 개발

```bash
npm install
npm run dev
```

개발·릴리즈·배포 규칙은 [AGENTS.md](AGENTS.md).
